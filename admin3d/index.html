Test 3D depth.

Runs the same pod tracking as the live app, but positions each dot with real depth (from data/pod-3d.json) instead of pinning it flat to the glass. Walking sideways is the actual test: a wrong depth makes a dot slide against its real feature; a correct one stays put.

Not linked from the public site or the admin page. Nothing here changes the live 2D app, which keeps using data/pod.json exactly as before.

The camera image stays on your device. Nothing is uploaded.
