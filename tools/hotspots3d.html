How do I get a token?
  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories, and pick this repository.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  4. Set an expiry (30 to 90 days), generate, copy the token and paste it above.

Anyone who has the token can change this repository, so keep it private. It is sent only to api.github.com and is never written into the code. Kept separate from the 2D placement tool's own remembered token.
